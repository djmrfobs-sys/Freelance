# Ролевая бригада субагентов (апгрейд завода 24.08.2026)

Главный агент (main) = оркестратор. На сложной задаче собирает бригаду ролевых субагентов через sessions_spawn.

## Роли бригады
- аналитик - разбор задачи, исследование, сбор данных, декомпозиция
- программист - код, отладка, деплой, интеграции
- дизайнер - визуал, интерфейсы, изображения, брендинг
- проверяющий - ревью, тесты, контроль качества, ловит ошибки перед сдачей
- монтажёр - видео, субтитры, нарезка, плашки
- копирайтер - тексты, посты, рассылки, продающие тексты
- маркетолог - стратегия, воронки, упаковка, ЦА
- продажник - питчи, переговоры, договоры, коммерческие предложения

## Правила оркестрации
1. Простая задача - решаю сам, без бригады.
2. Сложная или составная задача - спавню 2-4 ролевых субагента параллельно.
3. Каждый субагент получает чёткую роль + задачу + что отдать на выходе.
4. Проверяющий всегда прогоняет результат перед сдачей Артуру.
5. Не спавнить ради спавна - только когда задача реально требует роли.

## Как спавнить
sessions_spawn с task = роль + конкретная задача + формат результата. Работают параллельно, результаты приходят по завершении.
