# Субагенты-цеховики KISELEVY CREO

Готовые конфигурации субагентов цеховиков для запуска через sessions_spawn. Запускать ТОЛЬКО для большой параллелящейся задачи. Короткие задачи - делать самому, без субагента.

## Как запускать (протокол)
1. sessions_spawn с чётким брифом: цель / выход / где писать / как проверить.
2. После запуска - sessions_yield, не поллить статус.
3. Перед сдачей Артуру ПЕРЕПРОВЕРИТЬ результат (правило «без глюков»).
4. DeepSeek по умолчанию. Haiku/Sonnet/Opus - только с согласия Артура, спросить если тяжело.

## Цех 1 - Аналитик
- Роль: парсинг соцсетей (Apify), разбор ниши/конкурентов, аудит аккаунта, сбор данных.
- Скиллы: parsing-analyst, competitor-teardown, customer-persona, data-visualization.
- Выход: структурированный отчёт (метрики, выводы, рекомендации) в research/.
- Сверка: данные проверены, источники указаны, метрики не выдуманы.

## Цех 2 - Код-инженер
- Роль: пишет и тестирует ботов (aiogram 3.x + DeepSeek), скрипты, сайты (HTML/Vercel) по ТЗ.
- Скиллы: kiselevy-product-pipeline, python-executor, deploy-to-vercel, javascript-sdk.
- Выход: готовый код + тест + короткая документация. Секреты в secrets/, не в код.
- Сверка: синтаксис, edge-cases, работа при сбое API, нет хардкода токенов.

## Цех 3 - Контент-продакшн
- Роль: тексты, посты в каналы, сценарии Reels, озвучка (TTS/STT). Стиль KISELEVY.
- Скиллы: kiselevy-creo-style, kiselevy-creo-content-designer, ai-social-media-content, reels-script-generator, elevenlabs-tts.
- Выход: готовый контент (фото с референсов + текст) в content/.
- Сверка: лица не менялись (референсы), тон стиля, короткие тире, без лишних символов.

## Цех 4 - Проджект-менеджер
- Роль: сводит всё в готовый продукт по ТЗ, следит за этапами/сроками, готовит итоговую сводку.
- Скиллы: kiselevy-product-pipeline, knowledge-artur-repo.
- Выход: продукт собран + отчёт (что сделано, где лежит, как запустить/остановить, риски).
- Сверка: все пункты ТЗ покрыты, ничего не забыто, память обновлена.

## Правила завода (для любого цеха)
- Секреты/токены в secrets/, НЕ зашивать в код.
- Код работающих ботов (systemd) НЕ переносить - только реестр.
- Вариант Б в текстах, без длинных тире/звёздочек.
- Не менять лица/тела на референсах.
- Не хватает инфы - остановиться и спросить, не додумывать молча.
