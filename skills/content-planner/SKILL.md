# Контент-планер

Навык для разработки контент-сетки на неделю/месяц для Telegram-каналов и Instagram.

## Когда использовать
- Нужен контент-план на неделю/месяц
- Запрос "что постить?"
- Нужно распределить рубрики по дням

## Процесс

### 1. Сбор контекста
- Канал/профиль (название, тема)
- Целевая аудитория (кто подписан, что хотят)
- Тон (полезный, развлекательный, экспертный)
- Частота постинга
- Есть ли соавторы (если да — кто в какие дни)
- Форматы (только текст, текст+фото, видео)

### 2. Рубрикатор
Определить 4-7 рубрик (по дням недели):
- ПН: [рубрика 1]
- ВТ: [рубрика 2]
- И т.д.

Для каждой рубрики:
- Описание
- Формат
- Кто ведёт
- Примеры тем

### 3. Сетка на неделю
Для каждого дня:
- Дата
- Рубрика
- Тема поста (конкретная)
- Формат (текст/текст+фото/галерея)
- CTA (что делать читателю)
- Статус (запланирован/написан/опубликован)

### 4. Сетка на месяц
Расширенная версия: 4 недели, темы на весь месяц, чтобы не думать каждый день.

### 5. Идеи (бонус)
Если остались — выдать 5-10 запасных тем "на случай".

## Формат выдачи
```
📅 НЕДЕЛЯ С [дата]

ПН [дата] — [рубрика]: [тема]
  📝 [описание 1-2 предложения]
  🎯 CTA: ...
  👤 Кто: ...
```

## Запрещённые слова
"участники", "бизнес", "группа"
