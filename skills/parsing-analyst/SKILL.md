# Парсинг-аналитик

Навык для глубокого анализа Instagram-аккаунтов через Apify-парсинг.

## Когда использовать
- Пользователь даёт ссылку на Instagram-аккаунт
- Нужен разбор "почему не растёт"
- Анализ конкурента перед стратегией
- Подготовка питча клиенту

## Процесс

### 1. Запуск парсинга
Запустить: python3 ~/workspace-neuro/scripts/parse_instagram_full.py <username>

### 2. Анализ структуры
Из результатов парсинга:
- **Количество подписчиков / подписок** — соотношение
- **Частота постинга** — когда последний пост, как часто
- **Типы контента**: Reels vs Carousel vs Photo vs Video
- **Темы постов** — о чём пишет
- **Хэштеги** — какие использует, топ

### 3. Анализ контента
- **Формат заголовков**: hook-body-cta или нет
- **Длина текстов**: оптимальная / слишком длинная
- **Визуал**: цветовая гамма, стиль, качество
- **Реакции**: среднее количество лайков/просмотров на пост vs подписчики

### 4. Слабые места (красные флаги)
- Редкий постинг (реже 1 раза в неделю)
- Нет CTA в постах
- Нет ссылки в bio / битая ссылка
- Нет highlights / пустые highlights
- Разнобой в визуале
- Холодный аккаунт (нет активности)

### 5. Точки роста (рекомендации)
- Конкретные: что изменить, что добавить
- Последовательность: что делать в первую неделю

## Формат выдачи
```
📊 Анализ @username

СТРУКТУРА:
• Подписчики: ...
• Постов/неделю: ...
• Форматы: ...

КОНТЕНТ:
• Сильные стороны: ...
• Слабые: ...
• Топ-3 темы: ...

РЕКОМЕНДАЦИИ:
1. [сделать завтра]
2. [сделать на неделе]
3. [сделать в этом месяце]
```

## Важно
- Не делать выводов без данных
- Не использовать слова "ужасно", "провал"
- Только факты и рекомендации
