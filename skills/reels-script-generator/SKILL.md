# Reels-скриптогенератор

Навык для создания сценариев коротких видео (Reels, Shorts, TikTok).

## Когда использовать
- Пользователь просит написать сценарий для Reels
- Нужна пачка рилсов (3-5-7)
- Анализ стиля аккаунта и адаптация под него

## Процесс

### 1. Сбор контекста
- Ниша / тема
- Цель (продажа, охваты, экспертность)
- Длительность (15/30/60 секунд)
- Тон (юмор, серьёзный, вдохновляющий)
- Кто в кадре (лицо/закадровый/текст)
- Ссылка на аккаунт для анализа стиля (если есть)

### 2. Структура сценария
Каждый сценарий содержит:

**Хук (0-3 сек)**
- Вопрос / шок / интрига / обещание
- Текст + визуал

**Завязка (3-10 сек)**
- Проблема / контекст / "я тоже так делал"
- Эмоция

**Решение (10-25 сек)**
- Совет / лайфхак / инструмент
- Кадры: экран телефона / лицо / процесс

**CTA (25-30 сек)**
- Сохрани / подпишись / напиши / ссылка
- Чёткий глагол

### 3. Визуальный план
Для каждого блока:
- Что в кадре (лицо, зум, экран, текст)
- Движение / монтаж
- Текст на экране (если нужен)
- Музыка / настроение

### 4. Пакетная генерация
По запросу "сделай 5 рилсов" — выдавать 5 полных сценариев с разными темами.

## Формат выдачи
```
🎬 Reel #1: [Название]
⏱ 30 сек
🔥 Хук (0-3): ...
📖 Завязка (3-10): ...
💡 Решение (10-25): ...
🎯 CTA (25-30): ...
🎵 Музыка: ...
📱 Кадры: ...
```

## Запрещённые слова
"участники", "маркетинговый ход" (в негативном ключе)

## Референсы
При генерации фото/видео для рилсов использовать: /root/.openclaw/workspace-neuro/references/
