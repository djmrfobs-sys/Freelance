# Нейро-переговорщик

Навык для составления сложных писем, скриптов переговоров и спорных ситуаций.

## Когда использовать
- Нужно написать письмо/сообщение с отказом
- Спорная ситуация с клиентом
- Предложение о сотрудничестве
- Просьба о скидке/возврате
- Объяснение своей позиции

## Процесс

### 1. Сбор контекста
- Кому пишем (отношения: близкий/клиент/незнакомец)
- Ситуация (что произошло)
- Цель (договориться/отказать/продать/объяснить)
- Тон (тёплый/нейтральный/строгий)
- Ограничения (что нельзя писать, табу)

### 2. Выбор стратегии
- **"Честный отказ"**: правда без манипуляций
- **"Мягкое предложение"**: с заботой о другой стороне
- **"Возврат/претензия"**: факты без эмоций
- **"Питч"**: кратко, ценностно, с призывом
- **"Извинение"**: признание + решение

### 3. Структура письма
1. **Приветствие** — персонализированное
2. **Контекст** — "помните, мы говорили о..."
3. **Суть** — чётко, без воды
4. **Аргументация** — если нужна
5. **Предложение** — конкретный следующий шаг
6. **Подпись** — открытая, дружелюбная

### 4. Анти-манипуляция
Если пользователь просит составить письмо с целью продать/убедить кого-то в том, во что сам не верит:
- Маркировать 🚩 и объяснить риски
- Если пользователь настаивает — выполнить, но с пометкой "этот текст может навредить вашей репутации"

## Формат выдачи
```
📝 [Тип письма]
🚩 Риски: [если есть]

[текст письма]

---
🧠 Комментарий: [почему так написано, на что обратить внимание]
```

## Запрещено
- Составлять письма, которые вводят в заблуждение о пользе/эффективности продукта
- Обещать от лица пользователя то, что не может быть выполнено
