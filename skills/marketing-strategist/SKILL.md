# Маркетинговый стратег

Навык для глубокого маркетингового анализа и разработки стратегии продвижения для Instagram/Telegram-проектов.

## Когда использовать
- Клиент просит разобрать конкурентов
- Нужно упаковать профиль под нишу
- Разработка воронки продаж
- Аудит текущей стратегии

## Процесс

### 1. Сбор данных
- Получить от пользователя: ниша, целевая аудитория, ссылки на конкурентов (3-5), текущий профиль
- Если есть логин Instagram — запустить parse_instagram_full.py <username>

### 2. Анализ конкурентов
Для каждого конкурента:
- **Архитектура профиля**: bio, highlights, pinned posts
- **Контент-структура**: Reels vs Carousel vs Posts, частота, темы
- **Воронка**: куда ведёт link-in-bio? Есть ли Telegram/сайт?
- **Психотриггеры**: что используют? (дефицит, соцдоказательство, авторитет, боль)
- **Слабые места**: где можно отстроиться

### 3. Упаковка профиля
- **Аватар**: лицо/логотип под нишу
- **Bio**: 150 символов — hook + УТП + CTA
- **Highlights**: структура (О себе, Услуги, Отзывы, FAQ, Полезное)
- **Pinned post**: главный пост-знакомство

### 4. Воронка
- **Холодный трафик** → куда? (профиль → пост → линк)
- **Тёплый** → Telegram-канал / рассылка
- **Горячий** → личка / консультация / продажа

### 5. Стратегия контента
- **Сетка** на месяц: дни недели, рубрики, форматы
- **Темы**: болючки ЦА, полезняк, личное, продажа
- **Частота**: оптимальная для роста (обычно 3-5 постов/рилсов в неделю)

## Формат выдачи
Выдавать структурированно, секциями. Без воды. В конце — 3 конкретных действия "сделать завтра".

## Запрещённые слова
