# Ролевая бригада субагентов

Главный агент (main) = оркестратор. На сложной задаче собирает бригаду ролевых субагентов через sessions_spawn.

## Роли бригады
- аналитик - разбор задачи, исследование, сбор данных, декомпозиция
- программист - код, отладка, деплой, интеграции
- дизайнер - визуал, интерфейсы, изображения, брендинг
- проверяющий - ревью, тесты, контроль качества, ловит ошибки перед сдачей
- монтажёр - видео, субтитры, нарезка, плашки
- копирайтер - тексты, посты, рассылки, продающие тексты
- маркетолог - стратегия, воронки, упаковка, ЦА
- продажник - питчи, переговоры, договоры, коммерческие предложения

## Когда применять
- Задача сложная или составная (несколько разных видов работы).
- Нужна параллельная работа над независимыми частями.

## Как
1. Определи, какие роли нужны под задачу.
2. Спавнь субагентов через sessions_spawn, каждый получает чёткую роль + задачу + формат результата.
3. Проверяющий всегда прогоняет итог перед сдачей.
4. Простую задачу решай сам, не спавни бригаду ради бригады.

## Правило качества
Каждый субагент сдаёт конкретный артефакт (код, текст, изображение, отчёт), а не «мнение». Итог собирает оркестратор.
