# ТЗ: кнопки переключения модели у Джарвиса

## Цель
Заменить текстовые команды ("/model sonnet") на удобные inline-кнопки в Telegram — один тап вместо набора текста.

## Поведение
- Две кнопки, доступные в чате с ботом (например через команду /menu или прямо в приветственном сообщении, закреплённом сообщении, или всплывающие после каждого ответа — на усмотрение реализации):
  - **"💬 Спросить (DeepSeek)"** — обычные вопросы, консультации, быстрые ответы
  - **"🔧 Собрать проект (Sonnet 5)"** — переключение перед реальной сборкой по конвейеру
- При нажатии кнопки — бот переключает активную модель для этого чата
- После переключения — бот коротко подтверждает: "Окей, теперь работаю на Sonnet 5" / "Вернулся на DeepSeek"
- Кнопки должны быть видны постоянно (не пропадать после одного использования) — переключение может понадобиться много раз за день

## Технические детали
- Реализация через Telegram Bot API `reply_markup.inline_keyboard` (или `ReplyKeyboardMarkup`, если удобнее видеть кнопки в поле ввода постоянно, а не только под сообщением — уточни, какой вариант лучше ложится в архитектуру openclaw)
- Обработчик callback от кнопки должен вызывать тот же код, что уже обрабатывает команду /model — не дублировать логику переключения
- Модель по умолчанию возвращается на DeepSeek — конкретно **deepseek/deepseek-v4-pro** (reasoning, high effort) как самую интеллектуальную версию DeepSeek на сегодня, а не базовый deepseek-chat. Обнови agents.defaults.model.primary соответственно; Sonnet 5 доступен и по кнопке, и по-прежнему командой /model sonnet

## Ограничения
- Не менять остальную логику конвейера — кнопки только про переключение модели, не про сам процесс сборки

## Definition of done
- Обе кнопки видны в чате и реально переключают модель
- Подтверждено живым тестом: нажатие каждой кнопки, ответ бота о смене модели, следующий вопрос реально обработан правильной моделью
- Сырой вывод: конфиг/код до и после добавления кнопок
