## СБОРКА PDF - ТЕХНИЧЕСКИЙ ОПЫТ
- Конвертация HTML->PDF через WeasyPrint (pip install --break-system-packages pymupdf/weasyprint)
- Кириллица: встроенный Helvetica НЕ поддерживает кириллицу (точки вместо букв). Использовать DejaVuSans/DejaVuSans-Bold (/usr/share/fonts/truetype/dejavu/)
- apply_redactions (PyMuPDF) НЕЛЬЗЯ: стирает видимые глифы, оставляя текстовый слой (контент пропадает из отображения)
- .page фикс. высоты 297mm + overflow:hidden = переполнение ОБРЕЗАЕТСЯ скрыто. Добавление текста -> разбивать на явные страницы (по 4 карточки) или ужимать
- break-inside:avoid заставляет карточки прыгать целиком на новую страницу, ломает раскладку
- Правильный путь: править HTML-ИСХОДНИК + пересобрать WeasyPrint, НЕ редактировать готовый PDF
