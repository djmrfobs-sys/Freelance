### Функционал (ТЗ выполнено)
- 10 врачей, суммарный стаж 140 лет (терапевт, кардиолог, невролог, гинеколог, психотерапевт, педиатр, эндокринолог, дерматолог, гастроэнтеролог, ортопед)
- Главное меню с кнопками врачей
- Карточка врача: специализация, стаж, зона ответственности, частые вопросы
- Диалог с врачом через DeepSeek API (ключ с .deepseek_key)
- История каждого кабинета - отдельный файл, автосохранение после каждого сообщения
- Восстановление после перезапуска (из JSON файлов)
- Резервная копия раз в сутки (memory.daily_backup)
- Кнопка "назад" - Главное меню
- Переключение между врачами без потери контекста
- "⚕️ Срочный вопрос" - быстрый короткий ответ (ai.ask_urgent)
- Стили ответа: короткий / подробный / пошаговый план (ai.ask_doctor, style параметр)
- "🔄 Консилиум" - несколько врачей (2-5) обсуждают случай (ai.ask_consilium)
- Напоминания: /rem 08:30 Текст, /delrem <id> (в clinic.db, проверка каждые 30 сек в background_loop)
- Экспорт всей истории в PDF (команда "📄 Экспорт в PDF", reportlab + DejaVu кириллица)
- Голос Кети -> текст через Groq Whisper (utils.transcribe_voice, ключ .groq_key)
- Фото/видео/документы от Кети - сохраняются (пока без глубокой обработки)
- Стиль ответов: без звёздочек, длинных тире, только нейтральные эмодзи (ai._clean_markdown)

### Модель
- DeepSeek deepseek-chat, температура 0.65 (обычный) / 0.4 (срочный) / 0.6 (консилиум)
- Ключ DeepSeek живой и работает (проверено: психотерапевт, терапевт отвечают правильно)

### Ключевые функции (для будущих правок)
- ai.ask_doctor(doc_id, text, history, style) - основной ответ
- ai.ask_urgent(doc_id, text) - срочный
- ai.ask_consilium(doc_ids, text, history, style) - консилиум
- ai._clean_markdown(text) - убирает *, —, –
- memory.init_cabinet/add_message/get_last_messages/save_cabinet/reset_cabinet/daily_backup
- utils.build_pdf / transcribe_voice / download_file

### Тест-вывод
