Это ОТДЕЛЬНЫЙ проект от clinic140 (врачи для Кети). Публичная клиника для массовой российской аудитории.

## Решения Артура (зафиксировано)
- **Цель**: клиника для РОССИЙСКОЙ аудитории, русскоязычная, на русском языке.
- **ИП**: у Артура открыто ИП и в России, и в Сербии (оба действуют). Клиника на российскую аудиторию.
- **Цена абонемента**: 1 690 руб/мес (уточнено Артуром, вместо моих 1500).
- **Врачи на старте**: 6 (ядро). Из clinic140.
- **Каждый врач = ОТДЕЛЬНЫЙ бот** (отдельный токен, свой чат, своя история, НЕ общий чат). Решение Артура.
- **Оплата**: CloudPayments (Cloud Payment). Пока ставим ЗАГЛУШКУ на кошелёк. Соберём проект целиком -> Артур отправит CloudPayments описание проекта для одобрения -> получат API ключи -> вставим реальную платёжку. Не блокируемся ожиданием ключей.
- **Сервер**: 4 ядра, 8 ГБ RAM, 2 ТБ - достаточно, НЕ апгрейдим железо.
- **БД**: PostgreSQL (не SQLite) - параллельные записи на 1000+ пользователей. Объяснил Артуру простыми словами (POSTGRES взят для большой клиники).
- **Масштаб**: 1000+ пользователей без глюков.
- **ТЗ пишем ЗДЕСЬ со мной** (не через генератор ТЗ megamind). Артур согласен.

## ЖЕЛЕЗНОЕ ТРЕБОВАНИЕ №1 (главный приоритет Артура)
ИСТОРИЯ КАЖДОГО АБОНЕМЕНТА (пользователя) СОХРАНЯЕТСЯ ПОЛНОСТЬЮ при ЛЮБЫХ сбоях, зависаниях ботов, новой сессии, перезагрузке сервера. Врач должен продолжать с того места, где остановился, а не начинать с чистого листа.
Технически: каждое сообщение сразу пишется в PostgreSQL (на диск) до ответа врача; при возврате бот подтягивает последние N сообщений (user_id, doctor_id) и передаёт врачу контекстом. Защита от задвоения при рестарте.
