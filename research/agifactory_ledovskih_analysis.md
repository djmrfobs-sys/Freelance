# Разбор продукта «Завод Джарвисов» (AgiFactory) — Дмитрий Ледовских

Дата изучения: 24.08.2026. Источники: aibasis.ru, t.me/s/dmitryledovskih, kb.mcdenil.com, t.me/AgiFactory_bot.

## Что это
- Бот @AgiFactory_bot «Завод ♾️ Джарвисов» — интерфейс продукта Дмитрия Ледовских (McDenil).
- Ледовских = эксперт по ИИ, школа «Нейробаза», курсы «Контент на вайбе», «Вайбкодинг», «Завод Нейроагентов».
- Продукт = курс (6 недель) + готовая система агентов, которую ученик собирает и запускает себе.

## Из чего технически сделан (стек)
- Движок: Claude Code (CLI) + Codex (OpenAI) — гибрид двух моделей на разных ботах.
- Среда: VS Code + терминал.
- Хостинг: VPS сервер (Ubuntu, за границей для доступа из РФ).
- Интерфейс: Telegram Bot API — НЕСКОЛЬКО ботов у одного агента.
- Скиллы: Markdown-инструкции (библиотека автора).
- Память: файлы (агент знает владельца, проекты).
- Субагенты: бригада ролей (аналитик, программист, дизайнер, проверяющий, монтажёр).
- Оркестратор: главный агент управляет остальными.

## Ключевые фишки (из канала автора)
1. Мульти-бот: 1 агент = несколько Telegram-ботов, общая память, параллельные диалоги. Один бот на Codex, второй на Claude, страхуют друг друга.
2. Бригада субагентов: на сложной задаче агент сам собирает команду по ролям и делит работу.
3. Оркестратор: 1 агент запускает и координирует других.
4. Скиллы обязательны (без них агент работает на 10%): скачивание видео IG/TikTok/YouTube, темы и контент, реклама конкурентов, монтаж голосом, аудит YouTube, парсинг 1000+ сайтов.
5. Автомонтаж: субагенты (транскриб, резка пауз, плашки, картинки) + OpenMontage.
6. Безопасность агента (отдельный модуль).
7. Приём: Claude Code за $20 работает как за $100 (через API/прокси).

## Сравнение с нашим Нейрозаводом
Архитектурно то же самое: агент с памятью + субагенты + скиллы + оркестратор + сервер + Telegram-боты. У меня всё это уже есть в OpenClaw (main, sessions_spawn, 89+ скиллов, MEMORY.md, 15 ботов).

Где Ледовских сильнее:
1. Упаковка и методология продаж (ЦА, упаковка услуги, договоры, первые касания).
2. Готовые авторские скиллы под контент/монтаж/парсинг.
3. Мульти-бот осознанно (1 агент = N ботов, общая память).
4. Ролевая бригада субагентов (монтажёр/дизайнер/аналитик/проверяющий).
5. Гибрид моделей Claude+Codex на разных ботах.

Что перенять к нам:
1. Прайс-лист (15–30 тыс за контент-агента/автоматизацию).
2. Методология продаж и упаковка (модуль 6 курса).
3. Осознанный мульти-бот и ролевые субагенты.
4. Причёсанная библиотека скиллов под задачи клиентов.

## Вывод
Наш завод не «хуже» технически — у нас другой фундамент (OpenClaw вместо голого Claude Code). У Ледовских сильнее продажи, упаковка и готовые скиллы. Берём у него прайс, методологию продаж и ролевую бригаду субагентов — остальное у нас уже есть.
