# Команды бота — короткий справочник (база знаний Завода Джарвисов)

Источник: статья kb.mcdenil.com, прислана Артуром 24.08.2026.

## Суть
11 команд: 6 повседневных (видны в меню Telegram при наборе /) + 5 для особых случаев (набираются руками).

## Мульти-бот
Команды работают в каждом боте агента одинаково. /reset, /clear, /stop действуют только на того бота, где набраны. Долгая память общая.

## Шестёрка из меню Telegram

### /start — главное меню
- Настроен: короткое приветствие + список команд.
- Только установлен: bootstrap (имя, чем занимаешься, цели) → USER.md, GOALS.md, MEMORY.md.
- Когда: первый раз обязательно. В жизни почти никогда.

### /stop — остановить задачу
Прерывает текущую задачу. Сначала по-хорошему, если не слушается — жёстко через 3 сек.
Когда: печатает >5 мин (но большие задачи могут думать 10-20 мин — подожди); начал слать много сообщений без просьбы; передумал в процессе.
Важно: обрывает только текущую задачу, контекст сохраняется (можно «продолжай»).

### /reset — новая сессия (главная команда экономии лимита)
Очищает контекст текущего разговора. Долгосрочная память (SOUL, MEMORY, USER, GOALS) НЕ трогается.
Зачем: каждое сообщение пересылает всю историю → платишь токенами. /reset перед новой темой = минимальный расход.
Что теряется: только обсуждённое в сессии. Что остаётся: файлы личности, знания, проекты.
Совет: каждое утро начинай с /reset.

### /settings — настройки
Inline-меню из 6 пунктов: Модель (Haiku/Sonnet/Opus), Режим (Обычный/Авто), Переменные окружения (API-ключи), Часовой пояс, Дневной лимит, Перезагрузка.
Когда: первая настройка; добавить ключ (только через /settings → Переменные, не обычным сообщением); сменить модель; перезагрузить агента.

### /connect — VS Code туннель
Прямая линия браузер ↔ сервер. Видно все файлы агента как папку.
Как: /connect → авторизация GitHub (код XXXX-XXXX) → ссылка vscode.dev. Без SSH и терминала.
Когда: поправить SOUL.md, добавить знание (workspace/knowledge/), посмотреть код, поставить свой скилл.
Важно: защищено GitHub-аккаунтом, токен живёт ~сутки.

### /status — статус системы
Сводка: модель, режим, часовой пояс, активность сессии, потрачено сегодня vs лимит (светофор 🟢/🟡/🔴).
Когда: утром; перед долгой задачей; раз в неделю.

## Пять команд для особых случаев (не в меню, руками)

### /log — лог SSH-доступа
Последние 50 записей, кто заходил на сервер по SSH. Для контроля.
Когда: раз в месяц; при подозрении на странности.

### /privacy — политика обработки данных
Показывает DATA-POLICY.md: что хранится у тебя, что уходит в Anthropic, что не передаётся.
Когда: один раз в начале; перед чувствительной темой.

### /revoke — отозвать SSH-доступ оператора
Выгоняет ключ оператора. После этого никто извне не зайдёт (ни обновления, ни поддержка).
Когда: закрыть дверь на отпуск; при подозрении на компрометацию.
Имей в виду: обновления перестанут приходить. Возврат — через /grant.

### /grant — вернуть SSH-доступ
Возвращает ключ оператора после подтверждения.
Когда: после /revoke, если передумал.

### /telemetry on|off — синхронизация с Конструктором
Ежечасный отчёт «Завод Джарвисов», что агент жив + версия. По умолчанию вкл.
/telemetry — статус; /telemetry off — отключить (пропустишь уведомления об обновлениях).

## Светофор команд
- 🟢 ПОВСЕДНЕВНЫЕ: /start · /stop · /reset · /settings · /connect · /status (в меню).
- 🟡 КОНТРОЛЬ/ДОСТУП: /log · /privacy · /revoke · /grant · /telemetry (руками, раз в месяц).
- 🔴 ОПАСНЫЕ: /revoke (обновления перестанут), /telemetry off (Конструктор не узнает). Лучше не нажимать «на пробу».

## Главный совет
Главная привычка — /reset перед каждой новой темой: экономит лимит, разгружает голову, делает ответы точнее.
Разница: /stop = «прерви текущее» (память остаётся); /reset = «забудь разговор» (чистый лист).
