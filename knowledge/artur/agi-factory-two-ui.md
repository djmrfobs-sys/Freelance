# Два интерфейса — Telegram и VS Code одновременно (база знаний Завода Джарвисов)

Источник: статья kb.mcdenil.com, прислана Артуром 24.08.2026.

## Суть
Telegram и VS Code смотрят на один сервер. Даёшь задачу в Telegram — сразу видишь результат (файл, правку, коммит) в VS Code. И наоборот.

## Правила совместной работы
- Один диск — два входа, все файлы общие.
- Не править файл одновременно (дождаться пока агент закончит).
- Агент видит твои правки при следующем обращении.
- Git-изменения общие (коммит в VS Code виден в git log и наоборот).

## Когда что
- Дать задачу, написать код, создать сайт → Telegram.
- Быстро поправить опечатку, посмотреть результат, скачать файл, проверить MEMORY.md, запустить тесты → VS Code.

## Можно ли только через Telegram
Да. VS Code — дополнительный инструмент, не обязательный. Всё можно попросить агента сделать текстом.

## Применение к нашему заводу
У нас то же самое, два входа на один сервер: Telegram (чат с Артуром) + exec/read/write/edit (я работаю с файлами напрямую). Артуру VS Code не обязателен — он просит меня, я делаю и показываю результат в чате.
