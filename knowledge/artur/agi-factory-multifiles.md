# Как отправить несколько файлов и получить готовый результат (база знаний Завода Джарвисов)

Источник: статья kb.mcdenil.com, прислана Артуром 24.08.2026.

## Суть
Положи все файлы «в одну папку» + записка с задачей — агент разберёт их вместе. Одинаково работает с Claude и Codex.

## Как отправить
1. Отправь первый файл.
2. Не жди ответа — сразу отправь остальные.
3. Следующим сообщением напиши, что с ними сделать.
4. Подожди 3 секунды — бот передаст весь набор вместе (карусель).

## Применение к нашему заводу
У нас это уже есть:
- image tool — до 20 изображений за раз (карусель).
- read — несколько файлов (txt/md/json/csv) + PDF/Word/Excel (после установки pdftotext/python-docx/openpyxl).
То есть несколько файлов подряд я уже обрабатываю как единый набор — это его «карусель», у нас работает.

## Ограничения и доставка (у него)
- До 20 файлов / 100 МБ общий, каждый ≤ 20 МБ.
- Результат приходит вложениями; >20 файлов или >100 МБ — «Отправить остальные».
- Оригинал остаётся в рабочей папке агента (доставка = копия).
- Полученные программы/архивы сохраняются, но НЕ запускаются автоматически (защита сервера).
- Безопасность: ZIP распаковывается только через проверку (защита от записи за пределы папки). Файл блокируется, если внутри SSH/PEM-ключ или секреты (password/token/secret key/passphrase — в любых кодировках и форматах). Обычный текст со словом «секрет» не блокируется.
