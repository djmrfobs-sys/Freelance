# Как добавить API-ключ через /settings (база знаний Завода Джарвисов)

Источник: статья kb.mcdenil.com, прислана Артуром 24.08.2026.

## Суть
API-ключи никогда не писать в чат текстом. Только через меню /settings. «Ключи в сейф, а не на холодильник».

## Шаги
/settings → 🔑 Переменные окружения → выбрать сервис (или «Добавить свою») → скопировать ключ из консоли → прислать боту. Бот моментально удаляет сообщение с ключом и сохраняет в защищённое место.

## Готовые пресеты
Deepgram (голос), GitHub, Supabase, Vercel, OpenRouter, Voyage AI.

## Что важно
Если случайно отправил ключ обычным сообщением — он попадёт в логи. Сразу отозвать ключ в консоли сервиса и выпустить новый.

## Применение к нашему заводу
У меня то же правило: ключи храню в ~/.openclaw-neuro/ (deepseek_key, groq_key, apify_key, gemini_key, vercel_token), с правами chmod 600. В чат и память ключи не попадают. Пресеты у меня: Groq (вместо Deepgram), GitHub (SSH-ключ), Vercel (токен), Supabase (API), DeepSeek.
