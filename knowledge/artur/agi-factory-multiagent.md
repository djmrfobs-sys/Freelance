# Второй агент — отдельный, на своём сервере (база знаний Завода Джарвисов)

Источник: статья kb.mcdenil.com, прислана Артуром 24.08.2026.

## Суть
Второй агент = «отдельная квартира с другим жильцом»: своя память, свой сервер, свой ключ. Не путать со вторым ботом.

## Второй бот vs второй агент
- Второй бот: общая память/характер, тот же сервер, общий доступ к нейросети. Для работы в две руки. Сами, мгновенно.
- Второй агент: свои память/характер, отдельный сервер, свой доступ (отдельная оплата). Для другого клиента/проекта. По согласованию.

## Когда нужен второй агент
- Делаешь агента другому человеку (клиент/коллега) — своя память, не смешанная с твоей.
- Отдельный проект с отдельной головой (агент вообще не знает про дела другого).

## Что нужно
- Отдельный сервер (новый VPS, мин 2 ГБ памяти). Один сервер = один агент.
- Свой доступ к нейросети (Claude/Codex) — отдельная подписка/оплата.
- Согласование («слот» = разрешение на ещё одного агента).

## Как подключить
@AgiFactory_bot → «Запросить ещё одного агента» → заявка на одобрение → установка (новый сервер, другой IP).

## Как живут дальше
Каждый сам по себе: память не смешивается. Обновляются отдельно. Оба под твоим аккаунтом.

## Ограничения
- Память сервера (2 ГБ на агента, двум тесно).
- Деньги (отдельная оплата за каждого).
- Один сервер = один независимый агент.

## Применение к нашему заводу
У нас это уже есть: несколько gateway-профилей = отдельные агенты.
- helper (main/Нейро) — основной.
- rodion (KVANT profile) — отдельный агент.
- keti (workspace-keti) — отдельный.
То есть у нас уже несколько «агентов» (профилей) + 15 ботов. Можем заводить отдельный профиль под клиента = его «второй агент». Разница: у него новый VPS под каждого, у нас — профиль в одном gateway.
