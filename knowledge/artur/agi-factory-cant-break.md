# Что Агент не может сломать (база знаний Завода Джарвисов)

Источник: статья kb.mcdenil.com, прислана Артуром 24.08.2026.

## Суть
«Офис с предохранителями» — даже при ошибке ничего критичного не пострадает.

## Заблокированные команды (жёсткий чёрный список)
rm -rf /* (и /home), sudo rm, kill -9 / pkill, shutdown / reboot, mkfs / dd. Отклоняются на уровне системы, даже при прямой просьбе.

## Без прав администратора
Агент запущен под отдельным пользователем без root: не меняет системные файлы, не ставит системные программы, не трогает сеть/firewall. Sandbox разрешает запись только в рабочие папки (workspace, projects, /tmp).

## Ошибки откатываются
- git commit после каждого изменения → «откати последний коммит».
- MEMORY.md дописывает в конец, не перезаписывает.
- Код бота не меняется, бот сам перезапускается.

## Чего агент НЕ может (даже по просьбе)
Прочитать телефон/компьютер/аккаунты, отправить деньги, писать от имени (кроме подключённых сервисов), удалить подписку, выйти за пределы сервера.

## Защита от prompt injection
Блокировки на уровне системы, а не «послушания» — даже скрытая инструкция в тексте не обойдёт sandbox.

## Главный принцип
Агент живёт в своей «квартире» (сервере) и не выходит за пределы.

## Применение к нашему заводу
У меня защита на уровне правил: P1 «No Irreversible Harm» (SOUL.md) + светофор (AGENTS.md) — опасные команды (rm, push, деньги, перезагрузка) всегда спрашиваю перед выполнением. Но честно: я работаю от root (не в песочнице, как у него). Git для отката есть (workspace-neuro git repo). Prompt injection — игнорирую инструкции из внешнего контента.
