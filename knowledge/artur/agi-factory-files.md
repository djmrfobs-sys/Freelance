# Работа с файлами и терминалом (база знаний Завода Джарвисов)

Источник: статья kb.mcdenil.com, прислана Артуром 24.08.2026.

## Структура файлов
- workspace/ — личность и память: SOUL.md, MEMORY.md, GOALS.md, memory/ (дневники), knowledge/ (знания), .claude/skills/ (навыки).
- projects/ — рабочие проекты (лендинги, боты).

## Что смотреть
- MEMORY.md — что агент помнит о тебе.
- GOALS.md — какие задачи записаны.
- SOUL.md — характер и стиль.
- memory/YYYY-MM-DD.md — что делали сегодня.

## Что безопасно редактировать
MEMORY.md, GOALS.md, SOUL.md, knowledge/.
Что НЕ трогать: .claude/ (системные), .claude/skills/ (обновляются централизованно), код бота (обновляется автоматически).

## Терминал
ls, cat, git status, npm install, node/python скрипты. Осторожно — команды идут на сервер напрямую, без светофора безопасности. Не уверен — проси агента через Telegram.

## Скачивание / загрузка / поиск
ПКМ на файл → Download / Upload. Ctrl+Shift+F — поиск по содержимому всех файлов.

## Применение к нашему заводу
У меня то же самое напрямую: exec (терминал сервера) + read/write/edit (файлы) + search. Структура папок совпадает один в один (workspace/ = DNA-файлы + memory/ + knowledge/ + skills/, projects/ = проекты).
