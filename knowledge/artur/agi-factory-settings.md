# Меню /settings — карта по вкладкам (база знаний Завода Джарвисов)

Источник: статья kb.mcdenil.com, прислана Артуром 24.08.2026.

## Суть
/settings открывает меню «⚙️ Настройки» с 8 вкладками. По умолчанию разумно — можно работать месяцами без правок. В первый раз: Модель, Часовой пояс, Переменные окружения (Deepgram).

## 8 вкладок

### 1. 🤖 Модель (Claude: Haiku / Sonnet / Opus)
- Haiku — лёгкая, быстрая, дешёвая, для простых задач.
- Sonnet — золотая середина, стоит по умолчанию.
- Opus — самая умная, для сложного анализа.
- Max ($100+): ставь Opus и не трогай. Pro ($20): оставляй Sonnet.
- Совет: одна основная модель, не переключать «на пробу».

### 2. 🛠 Режим
- Обычный — спрашивает перед рискованными действиями (удаление, перезапись).
- Авто — действует сам без подтверждений.
- Новичок: Обычный. Доверяешь в конкретных задачах — Авто.

### 3. 🔑 Переменные окружения (API-ключи, самая частая вкладка)
6 предустановленных сервисов:
- Deepgram (голос, $200 бонус).
- GitHub (commit/push/pull/PR).
- Supabase (база данных).
- Vercel (деплой сайтов).
- OpenRouter (единая «розетка» к GPT/Gemini/DeepSeek/Llama/FLUX/SD/Sora).
- Voyage AI (семантический поиск по памяти — находит по смыслу, не по словам).
Ключ отправляется сообщением, бот сразу удаляет его и сохраняет в ~/.agent/.env. Никогда не шли ключ «просто так» вне /settings.
➕ Добавить переменную — любой свой ключ.

### 4. 🕐 Часовой пояс (7 вариантов)
UTC, Europe/Moscow, Europe/Kiev, Asia/Almaty, Asia/Vladivostok, America/New_York, America/Los_Angeles.
Влияет: дневники memory/, план дня, команду времени. Один раз и забыть.

### 5. 💰 Лимит ($10/$25/$50/$100/$200, по умолчанию $50)
Для подписчиков (Pro/Max) — не актуален, это индикатор «во сколько обошлись бы по API».
Важен только при работе через API (свой Anthropic-ключ или OpenRouter).
Светофор: 🟢 до 80% · 🟡 80% предупреждает · 🔴 100% блокирует до завтра.

### 6. 🔄 Перезагрузка
Безопасный рестарт бота (systemd поднимет через секунду). Контекст/память/ключи сохраняются.
Когда: после правки .env руками; после обновления; если бот «тормозит».

### 7. 🧠 Нейросеть
Мозг агента: Claude Code (по умолчанию, по подписке Claude Max) или Codex (OpenAI, по ChatGPT Plus).
При переключении память/проекты/настройки сохраняются, меняется только «мотор».

### 8. 🤖 Мои боты (мульти-бот)
Список Telegram-ботов агента + добавить ещё (второй, третий) на ту же память/характер.
Пока один бот занят — пишешь другому. Память общая, разговор у каждого свой.
➕ Добавить бота: создать в @BotFather → прислать токен → агент проверит и перезапустится.
Дополнительный бот отвечает только владельцу.

### ✖ Закрыть
Удаляет сообщение меню, без изменений.

## Частота использования
- 🟢 Часто: Переменные окружения (новые ключи).
- 🟡 Раз в полгода: Модель, Режим, Перезагрузка.
- 🔴 Один раз: Часовой пояс, Лимит (подписчикам не трогать).

## Первый заход (совет)
Max от $100 → Opus надолго. Pro $20 → Sonnet. Часовой пояс свой. Лимит не трогай (если подписка). Подключи Deepgram (голос). Режим — Обычный.

## Применение к нашему заводу
- Модель: у нас DeepSeek (по правилу Артура) + Claude Code на сервере (Max). Можем точечно гонять Opus на тяжёлых задачах.
- Голос: у нас Groq Whisper (вместо Deepgram).
- Ключи: уже есть DeepSeek, Groq, Apify, Gemini, Supabase, Vercel, GitHub.
- Мульти-бот: у нас уже 15 ботов в одном gateway (его фишка «Мои боты»).
- Семантический поиск: у нас memory_search (аналог Voyage AI).
- Часовой пояс: у меня UTC — стоит выставить Артуру Europe/Belgrade (Нови-Сад, Сербия).
