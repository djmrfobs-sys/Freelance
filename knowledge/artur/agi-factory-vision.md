# Что Агент видит — фото, документы, видео (база знаний Завода Джарвисов)

Источник: статья kb.mcdenil.com, прислана Артуром 24.08.2026.

## Суть
В чат можно бросать: фото (Vision), документы (PDF/Word/Excel/txt/md/csv/json/html/pptx), видео (анализ кадров), ссылки Google Docs/Sheets, карусель (несколько файлов = один запрос).

## Фото (Vision)
Читает: рукописные заметки, чеки, скрины, схемы, фото товара, меню. Подпись к фото = инструкция (без подписи просто «что на изображении?»).

## Документы
PDF (договоры, отчёты), Word, Excel, txt/md/csv/json/html/код, pptx (текст слайдов).

## Видео
Анализ ключевых кадров (не «смотрит как фильм»). Скринкасты, демо, записи с камеры.

## Карусель = один запрос
Несколько фото подряд → собираются в один запрос за 3 сек. 8 фото = 1 запрос (расход в 8 раз меньше). Смесь 3 фото + PDF + видео тоже работает. Пауза >3 сек = отдельные задачи.

## Google Docs/Sheets по ссылке
docs.google.com ссылка в тексте → агент сам скачивает содержимое. До 3 ссылок за сообщение, длинное обрезается до 30k символов. Нужен доступ «Anyone with the link».

## Что не умеет из коробки
- Аудиофайлы (.mp3/.wav/.m4a) как документы (только голосовые Telegram).
- Файлы >20 МБ (набор до 20 файлов / 100 МБ, исходящий до 50 МБ).
- Защищённые PDF с паролем.
- Закрытые Google Docs.
- Прямые ссылки YouTube/Vimeo/TikTok.

## Ключевая мысль: «Не умеешь? Научись.»
Агент на сервере может сам ставить программы, писать скрипты, добавлять обработчики. Спросить «что нужно чтобы ты умел X?» → агент ставит сам после «да». Это отличие от чат-бота — расширяется под задачи.

## Привычки
1. «Можно ли сфоткать?» вместо печати длинного описания.
2. Ссылки вместо копипаста (Google Docs/Sheets).
3. «Не умеешь? Научись.» — каждый раз когда не может формат/ссылку/сервис.

## Сравнение с нашим заводом (что извлечь)
Уже есть:
- Vision (фото) — image tool читает изображения.
- Чтение текстовых файлов — read (.md/.txt/.json/.csv/код).
- Карусель — image tool принимает до 20 изображений за раз.
- YouTube — yt-dlp уже стоит (скачивание видео).
- Ссылки — web_fetch открывает публичные страницы.
- ffmpeg — работа с аудио/видео.
- «Научись» — я тоже могу ставить инструменты (python, ffmpeg, yt-dlp).

Чего нет / стоит добавить:
1. PDF-парсинг — поставить pdftotext (poppler-utils) + pymupdf, чтобы читать PDF договоры/отчёты.
2. Word/Excel — python-docx, openpyxl для .docx/.xlsx.
3. Google Docs/Sheets по ссылке — web_fetch частично, но Google рендерит JS (нужен обход или gdown/публичный экспорт).

План: могу поставить pdftotext + python-docx + openpyxl за пару минут — тогда читаю PDF/Word/Excel как документы, как у него. Это дёшево и пригодится для договоров (KISELEVY CREO много .docx/.pdf).
