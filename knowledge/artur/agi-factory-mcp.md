# Что такое MCP и зачем он Агенту (база знаний Завода Джарвисов)

Источник: статья kb.mcdenil.com, прислана Артуром 24.08.2026.

## Суть
MCP (Model Context Protocol) = универсальная розетка между агентом и внешними сервисами. Один протокол, одна точка подключения, десятки возможностей. Не нужно разбираться в API каждого сервиса — «воткнул штепсель» в конфиг.

## Типы подключений
- Локальный — программа запускается на твоём сервере (Pencil — дизайн-макеты .pen). Данные не уходят наружу, безопаснее.
- Облачный — агент обращается к сервису в интернете (Supadata, Google Calendar). Данные по сети.

## Конфигурация
Все MCP-серверы в одном файле ~/.claude.json (секция mcpServers). Claude Code читает при запуске, подключается ко всем перечисленным.

## Отличие от API-ключей
- API-ключ = номер телефона: сам звонишь и говоришь что нужно.
- MCP = секретарь: говоришь задачу, он сам знает кому звонить и что говорить.

## Применение к нашему заводу
У меня уже есть набор инструментов (exec, web_fetch, read/write/edit, image_generate, video_generate, music_generate) — это аналог MCP: доступ к внешним возможностям. Отдельные MCP-серверы (Pencil, Google Calendar) могу подключить при необходимости через конфиг.
