# Три мастера слова — пост, сторис, сценарий (база знаний Завода Джарвисов)

Источник: статья kb.mcdenil.com, прислана Артуром 24.08.2026.

## Суть
3 контент-скилла: Писатель, Сторисмейкер, Сценарист. Общая привычка: первый раз просят «покажи пример» → запоминают стиль навсегда.

## Писатель (content-writer)
- Пост (3-5 коротких абзацев), карусель (5-10 слайдов: хук → суть → призыв), лайфхак (приём с цифрами).
- Главное правило: конкретика важнее полноты (не «в мире, где технологии…», а цифры, кейсы, живая речь).

## Сторисмейкер (instagram-stories)
- Фото → готовые изображения 1080×1920 с текстом (прямая загрузка в Instagram/Telegram).
- Серия 2-4 кадра с нарастанием: завязка → кульминация → панчлайн. Фирменный шрифт, градиент снизу, safe-зоны.

## Сценарист (youtube-scenario)
- По теме: структура (блоки по времени, ключевые мысли, переходы, open loops). Шпаргалка, не текст для зачитывания.
- По чужому ролику: ссылка YouTube → скачивание аудио → транскрипт → разбор (хук, структура, open loops) → адаптация под свою аудиторию.

## Что умеют / не умеют
- ✅ Посты, карусели, лайфхаки в стиле; готовые сторис; сценарий с нуля или по видео.
- ⚠️ Первый раз просит пример (учится стилю).
- ❌ Снимать/монтировать видео; дизайн с нуля (баннеры без фото).
