# Голос — Deepgram, Whisper и трюки (база знаний Завода Джарвисов)

Источник: статья kb.mcdenil.com, прислана Артуром 24.08.2026.

## Суть
Два пути распознавания голоса:
- Deepgram (облако, высокая точность) — платно, но $200 бонусом = пару лет.
- Whisper (локально, бесплатно навсегда) — чуть хуже русский, установка ~8 мин, медленнее (5-15 сек).

## Логика выбора (автоматически)
- Deepgram ключ подключён → голос через Deepgram.
- Нет ключа + Whisper установлен → локально.
- Ничего нет → меню «Подключить Deepgram» / «Установить Whisper».

## Deepgram
- console.deepgram.com → регистрация → $200 бонус.
- API Keys → Create Key → ключ один раз → /settings → Переменные → Deepgram.
- Технически: api.deepgram.com, модель nova-2, язык ru, smart_format (числа/даты/пунктуация авто).
- Расшифровка 1-3 сек.

## Whisper (локально)
- OpenAI, работает на своём сервере, без интернета/счетов.
- Когда: не хочешь отдавать голос наружу; принципиально не платить.
- Минусы: русский хуже, base путает похожие слова, установка 8 мин, медленнее.

## Лайфхаки
- Длинные голосовые (5-10 мин) — норм.
- Говори естественно, как с живым человеком (не «агент задача отчёт»).
- Числа и даты — smart_format сам форматирует («семьсот пятьдесят» → 750).
- Фон не страшен (машины, кафе).

## Когда текстом
- API-ключи/пароли (никогда голосом).
- Длинные термины, имена.
- Сложные таблицы цифр.

## Чиним проблемы
- «Расшифровываю» висит >30 сек → проблема интернета/API, перезапусти.
- Ошибки в тексте → исправь текстом «я имел в виду X, а не Y».
- $200 кончились → добавь $5-10 или переключись на Whisper.
- Голос не приходит → ни Deepgram ни Whisper не настроены, отправь голосовое, появится меню.

## Совет
Ставь Deepgram в первый день и забудь на годы.
