# GitHub — бэкап и совместная работа (база знаний Завода Джарвисов)

Источник: статья kb.mcdenil.com, прислана Артуром 24.08.2026.

## Суть
GitHub = сейф для кода и файлов с историей изменений. Бэкап проектов — если сломается диск/сервер, восстановишь одной командой.

## Подключение
- Personal Access Token: fine-grained (доступ к выбранным репо, github_pat_) или classic (ghp_, scope repo).
- /settings → 🔑 Переменные окружения → ➕ → имя GITHUB_TOKEN → токен. Никогда обычным сообщением.
- Проверка: «проверь доступ к GitHub» → curl с токеном → имя аккаунта.
- Аутентификация только HTTPS (не SSH).

## Что агент делает
Клонировать репо в ~/projects/, commit + push, создавать новые репо, работать с PR.

## Ошибки 403/404
Значит у токена нет доступа к репо (fine-grained не выбрал репо, или токен истёк через 90 дней).

## Автобэкап
Агент коммитит сам ([agent] action: описание), но push — только по просьбе (RED-операция). «После каждых 3 коммитов предлагай пушить» — запомнит и напомнит.
