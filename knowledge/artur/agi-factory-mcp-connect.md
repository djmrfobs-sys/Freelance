# Как подключить MCP-сервер — пошаговая инструкция (база знаний Завода Джарвисов)

Источник: статья kb.mcdenil.com, прислана Артуром 24.08.2026.

## Суть
Все MCP-серверы в одном файле ~/.claude.json → секция mcpServers. Добавить = дописать блок, удалить = стереть блок. Без перезапуска — подхватит при следующем сообщении (или после /reset).

## Два способа
1. Попросить агента: «Подключи MCP-сервер supadata, URL ...» — сам отредактирует ~/.claude.json.
2. Вручную через VS Code.

## Тип stdio (программа на сервере)
```json
{"type": "stdio", "command": "/путь/к/программе", "args": [...], "env": {"APIFY_TOKEN": "..."}}
```
Пример: npx @apify/mcp-server. Claude Code запускает программу и общается через stdin/stdout.

## Тип http (удалённый сервер)
```json
{"type": "http", "url": "https://адрес/путь", "headers": {"Authorization": "Bearer токен"}}
```
Пример: Supadata (данные с сайтов).

## Удаление / проверка
«Отключи MCP-сервер X» / «Какие MCP-серверы подключены?».

## Частые ошибки
- Сервер не появился → нужен /reset.
- «command not found» → не установлен npx/node, или неверный путь/права.
- Ошибка авторизации → проверить url/headers/env.

## Применение к нашему заводу
У меня набор инструментов уже есть (exec, web_fetch, read/write/edit, image_generate, video_generate, music_generate) — это аналог MCP-возможностей. Отдельные MCP-серверы (Apify, Supadata, Google Calendar) подключу при необходимости — в OpenClaw есть поддержка MCP-конфига.

## Совет (у него)
Начинать со Способа 1 — просто попросить агента (он аккуратно отредактирует ~/.claude.json). После подключения обязательно протестировать простым действием через новый сервер.
