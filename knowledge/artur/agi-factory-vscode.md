# Что такое VS Code Tunnel и зачем он нужен (база знаний Завода Джарвисов)

Источник: статья kb.mcdenil.com, прислана Артуром 24.08.2026.

## Суть
VS Code (редактор в браузере) + Tunnel (безопасное соединение с сервером) = доступ к файлам агента из любого браузера, как если бы сидел за его компьютером.
Аналогия: Telegram = переписка с сотрудником, VS Code Tunnel = зайти к нему в кабинет и посмотреть на монитор.

## Зачем
- Посмотреть результаты работы (файлы, скачать, отредактировать).
- Быстро поправить текст руками.
- Работать с кодом параллельно с агентом.
- Проверить/поправить память и настройки (MEMORY.md, SOUL.md, GOALS.md).

## Нужен ли всем
Нет. Если хватает Telegram — не трогать. Всё, что умеет VS Code, агент умеет сам по просьбе. Полезен если: хочешь видеть файлы глазами, пишешь код сам, тонко настраиваешь агента, любишь полный контроль.

## Применение к нашему заводу
У меня доступ к файлам сервера есть напрямую: exec (команды) + read/write/edit (файлы). Артуру VS Code Tunnel не обязателен — он просит меня, я делаю. Если захочет руками посмотреть — можно через SSH к MacBook или vscode.dev + Tailscale.
