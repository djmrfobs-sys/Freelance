# 5 примеров — что можно сделать с MCP (база знаний Завода Джарвисов)

Источник: статья kb.mcdenil.com, прислана Артуром 24.08.2026.

## Суть
MCP превращает агента из собеседника в рабочую лошадку: подключил сервис → описываешь задачу словами → агент сам вызывает действие.

## 5 примеров
1. Google Calendar — планирование: встречи, свободные окна, напоминания.
2. Gmail — почта: читать входящие, писать/отвечать, сортировать по важности.
3. Google Sheets — таблицы и CRM: читать, добавлять строки, считать итоги, сводки.
4. Pencil — дизайн макетов (.pen): менять текст/цвета, скриншоты, экспорт PNG.
5. Supadata — данные с сайтов: выжимка текста по URL, расшифровка YouTube, сбор товаров.

## Как подключить
«Подключи MCP-сервер [название], URL: [адрес]» (http) или «команда: npx [пакет]» (stdio). Агент сам отредактирует ~/.claude.json.

## Сводная таблица
Планирование → Google Calendar; почта → Gmail; таблицы/CRM → Google Sheets; дизайн → Pencil; аналитика → Supadata.

## Совет
Начинать с того, чем пользуешься каждый день. Не подключать всё сразу — один сервис, привык, потом следующий.

## Применение к нашему заводу
У меня уже есть близкие аналоги: web_fetch (аналог Supadata — читает страницы), Apify (парсинг сайтов/Instagram), image_generate + скиллы дизайна (аналог Pencil). Google Calendar/Gmail/Sheets подключу через API при необходимости — скажи, и настрою нужное.
