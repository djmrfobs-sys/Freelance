# 20 специалистов из коробки — команда Агента (база знаний Завода Джарвисов)

Источник: статья kb.mcdenil.com, прислана Артуром 24.08.2026.

## Суть
Внутри агента — команда: 20 специалистов (8 фоновых + 12 именных), каждый = скилл (инструкция). Агент сам зовёт нужного по задаче, не нужно писать «активируй скилл».

## Фоновая команда (8, работают всегда)
- Системный — читает SOUL/USER/MEMORY при запуске.
- Память — записывает о владельце.
- Сервер — диагностика, перезапуск, логи.
- Медиа — скачивание видео/аудио YouTube/Instagram/TikTok.
- Веб — открывает ссылки, читает страницы.
- Транскрипт — YouTube-видео в текст.
- Мониторинг — поиск по базе знаний/трендам.
- Напоминалка — напоминания и регулярные задачи.

## Именные специалисты (12, зовёт по словам)
Писатель, Сторисмейкер (1080×1920), Сценарист, Аналитик (тренды/ЦА), Интервьюер (25 вопросов), Разработчик (лендинги/боты/скрипты), Дизайнер (интерфейсы), Ревьюер (проверка кода), Копирайтер, Планировщик дня, Трекер привычек, Специалист по презентациям.

## Совет
Не учить все 20. Говорить задачу обычным языком. «Какие специалисты у тебя есть?» — перечислит. Чем точнее задача — тем точнее выбор.

## Применение к нашему заводу
У меня уже есть 89+ скиллов (в .agents/skills/) + ролевая бригада из 8 ролей (субагенты). Его 20 специалистов у меня покрыты и перекрыты:
- Фоновые: читаю SOUL/MEMORY, парсинг (Apify/yt-dlp), web_fetch, Groq Whisper (транскрипт), cron (напоминалка).
- Именные: скиллы контента (посты, reels, linkedin), кода, дизайна, презентаций в .agents/skills/.
Принцип тот же: выбираю нужный инструмент по задаче сам.
