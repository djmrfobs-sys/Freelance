# @translater_fobs_bot — v4.0 (READY)

Сербско-русский бот-переводчик (текст + голос + фото/OCR + озвучка TTS).

## Направления перевода
- Русский → Сербский (+ кнопка "🇬🇧 Перевести на английский")
- Сербский → Русский
- Английский → Русский

## Команды
- `/start` — приветствие и справка
- `/sr` — режим: сербский → русский (жёсткий)
- `/ru` — режим: русский → сербский (жёсткий)
- `/en` — режим: английский → русский (жёсткий)
- `/auto` — автодетект (по умолчанию)
- `/clear` — очистить историю диалога

## Архитектура
- **STT:** Groq Whisper large-v3-turbo (двухпроходная стратегия, конфликт-детекция)
- **Перевод:** DeepSeek (chat completions) + кэш переводов
- **OCR:** Gemini Vision (3 модели с fallback)
- **TTS:** Google Translate TTS + ffmpeg (параллельный, не блокирует ответ)
- **Хранение:** SQLite (dialog_history, lang_detection_log, translation_cache)

## Ключевые улучшения v4.0
1. **Кэш переводов** — повторяющиеся фразы переводятся мгновенно (2283x быстрее)
2. **Без истории** в каждом переводе — DeepSeek отвечает быстрее (0.8s)
3. **Параллельная TTS** — озвучка не блокирует текстовый ответ
4. **Только 3 языка** (SR/RU/EN), при неопределённости — честный возврат текста
5. **/clear реально чистит** БД
6. **Режимы /sr /ru /en** — жёсткий переключатель направления

## Запуск
```bash
systemctl restart serbian-translator-bot.service
systemctl status serbian-translator-bot.service
journalctl -u serbian-translator-bot.service -f
```

## Файлы
- `bot.py` — основной код (v4.0)
- `bot.py.bak_v3` — бэкап v3.0
- `translator_history.db` — SQLite (история + логи + кэш)

## Известные ограничения
- Скорость первого перевода зависит от DeepSeek (~1-10 сек), повторные — мгновенно
- Whisper-распознавание голоса ~1-2 сек + перевод — суммарно до ~5-8 сек на голосовое
- Голосовые тесты после обновления ещё не проводились (требует живого теста)
