# Git-версионирование workspace нейрозавода

## Зачем
Правки скиллов/конфигов сейчас необратимы — если что-то поломает поведение бота, непонятно, после какой правки. Git даёт точку отката.

## Шаги

1. `cd ~/.openclaw/workspace-neuro/` (или актуальный корень workspace)
2. Создай `.gitignore` ДО первого коммита — обязательно, иначе секреты попадут в историю навсегда:

```
secrets/
.env
*.token
state/*.sqlite
*.log
node_modules/
```

3. `git init`
4. `git add .`
5. **Прежде чем коммитить — проверь, что .gitignore реально исключил секреты**: `git status` не должен показывать файлы из secrets/, .env и т.п. Если показывает — `git rm --cached <файл>` и перепроверь .gitignore.
6. `git commit -m "initial state"`
7. Правило на будущее: коммит после каждой значимой правки скилла/конфига, с понятным сообщением (что и зачем поменяли)

## Важно
- Git сам по себе — НЕ бэкап (живёт на том же сервере). Но backup-neuro-zavod.sh уже архивирует весь workspace включая `.git/` — значит история коммитов автоматически попадает в B2 вместе с остальным.
- Если нужно посмотреть, что изменилось в конкретном скилле: `git log --oneline -- skills/<имя>/SKILL.md` и `git diff <commit1> <commit2> -- skills/<имя>/SKILL.md`

## Подтверждение
После настройки пришли сырой вывод `git log --oneline -1` и `git status` — покажет, что репозиторий инициализирован и чист (нет случайно незакоммиченных секретов).
