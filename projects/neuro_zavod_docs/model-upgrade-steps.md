# Апгрейд модели Джарвиса: DeepSeek → Claude Opus/Sonnet

## Что меняем
- Этапы ТЗ / Архитектура / Ревью конвейера → claude-opus-4-8
- Этап Сборка (генерация кода) → claude-sonnet-5
- DeepSeek полностью убрать из конфига ИМЕННО Джарвиса (остальные 14 ботов не трогать — там экономия оправдана)

## Шаги

1. Открой конфиг: `~/.openclaw-neuro/config.json5` (или актуальный путь профиля neuro)
2. Найди блок `agents.defaults.model` / `agents.defaults.models` — именно там сейчас прописан DeepSeek
3. Проверь блок provider для Anthropic — должен быть активный API-ключ. Если ключа нет или он только для Haiku — нужно расширить доступ в аккаунте Anthropic до Sonnet/Opus
4. Пропиши модели по этапам конвейера (если конфиг поддерживает per-stage override) либо, если такой возможности нет — используй универсально claude-sonnet-5 (компромисс между качеством и ценой на всех этапах), а claude-opus-4-8 держи опционально для особо сложных ТЗ
5. Убери DeepSeek из списка моделей именно этого агента
6. Сохрани конфиг
7. Перезапуск: если `gateway.reload.mode: hybrid` — применится автоматически. Если `off` — `systemctl --user restart openclaw-gateway.service`
8. **Проверка**: `systemctl --user status openclaw-gateway.service` — сервис должен быть active. Прогони один тестовый диалог с ботом и убедись, что ответы идут от Claude, а не DeepSeek (можно спросить бота напрямую "какая ты модель").

## После применения
Пришли сырой вывод `systemctl --user status openclaw-gateway.service` после рестарта — подтверждение, что применилось без ошибок конфига (как было с "models: Invalid input" ранее).
