# Аудит .agents/skills/ — поиск реальных дублей

Основной реестр (skills/INDEX.md, 104 скилла) уже готов. Эта папка — второй слой загрузки
(workspace/.agents/skills, ~95 файлов "с ресурсами"), ещё не проверен на дубли с основным.

## Шаги

1. Собери индекс так же, как для основного реестра:
```
for f in ~/.openclaw/workspace-neuro/.agents/skills/*/SKILL.md; do
  echo "=== $f ==="
  head -5 "$f"
done > agents-skills-index.txt
```

2. Сравни имена и description с skills/INDEX.md — найди пары, которые делают одно и то же под разными именами

3. Для реальных дублей: объедини в один файл (предпочтительно оставить версию из основного skills/, как канон), второй удали — но СНАЧАЛА убедись, что свежий бэкап уже прошёл (проверь `rclone ls b2:reservd/neuro-zavod/` на сегодняшнюю дату)

4. Для мёртвых скиллов (ни разу не сработавших, если есть invocation-лог) — кандидаты на удаление, но не обязательно срочно

5. Обнови skills/INDEX.md после любых изменений (по вашему же правилу)

## Важно
Не удаляй ничего без свежего подтверждённого бэкапа — это единственный шаг в списке дел, который необратим на диске.

## Подтверждение
Пришли сырой вывод: сколько реальных дублей нашлось, что объединено/удалено, финальное число скиллов в каждой из двух папок после чистки.
