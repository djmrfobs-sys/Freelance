## Конвейер производства (product-conveyor / kiselevy-product-pipeline)

Файл: `skills/kiselevy-product-pipeline/SKILL.md` (канонический путь на сервере может отличаться от черновика — уточнять)

Этапы: 0) проверка существующего → 1) сбор ТЗ (gate — не начинать без подтверждения, умные дефолты vs значимые вопросы) → 2) архитектура (+ применение стиля KISELEVY CREO) → 3) сборка (git-коммит после каждого модуля, секреты через .env, чекпоинты, протокол неясностей) → 4) самопроверка (реальный запуск, verification-before-completion) → 5) релиз (staging → боевой, отчёт "известные ограничения")

Правило отчётности: любой отчёт о проверке/числах — с сырым выводом команды, не пересказом.

## Disaster Recovery — ЗАКРЫТ ПОЛНОСТЬЮ
- Бэкап-скрипт: `/root/backups/backup-neuro-zavod.sh`
- Что входит: workspace-neuro (память, скиллы, проекты), + внешний код ботов (/root/workspace, /root/karen-bot), + memory/docs(договоры)/secrets/ключи/клиенты/контент/research
- Расписание: systemd timer, ежедневно 06:00, Persistent=true
- Внешнее хранилище: Backblaze B2, бакет `reservd`, путь `b2:reservd/neuro-zavod/`, через rclone (native B2, без endpoint в конфиге)
- Ротация: 30 дней и на диске, и в облаке
- Восстановление: `RESTORE.md` в workspace, ~20-30 минут с нуля
