# Клиника Рядом - ТЗ: Пробная версия + Карточка клиента + Личный кабинет

Артур, 12.08.2026. Требования зафиксированы.

## 1. Пробная версия (триал)
- Триал стартует в момент: пользователь отметил политику конфиденциальности (нажал "согласен") + нажал Старт.
- Продолжительность: 7 дней бесплатно от дня старта триала.
- Лимит в триале: 10 запросов в день БЕСПЛАТНО на КАЖДОГО врача отдельно (не суммарно).
- После окончания триала: бот АВТОМАТИЧЕСКИ предлагает продление - покупка в боте на 1 месяц за 1690 руб.

## 2. Личный кабинет
- У каждого абонента есть свой личный кабинет (статус абонемента, остаток триала/подписки, данные карточки, история).

## 3. Карточка клиента (обязательна ПЕРЕД общением с врачами)
- Перед началом общения пользователь заполняет карточку:
  - Имя
  - Возраст
  - Пол
  - Хронические заболевания
  - Что беспокоит (жалобы)
- Карточка хранится и передаётся врачам как постоянный контекст - врачи всегда видят её и общаются с учётом.
- Без заполненной карточки общаться с врачом нельзя.

## 4. Тариф
- Цена: 1690 руб/мес (доступ ко всем 6 врачам).
- Оплата через бота (заглушка CloudPayments сейчас).

## 5. Мессенджер Max (следующий шаг, отдельно)
- Возможно: у Max есть Bot API (dev.max.ru), создавать ботов могут ИП/юрлица.
- Нужна верификация ИП Артура, токен через @MasterBot.
- Отдельный объём после Telegram-версии.
