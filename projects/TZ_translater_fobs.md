## 1. Назначение

Личный Telegram-бот-переводчик Артура и Кети для повседневного общения в Сербии.
Основная задача: быстро переводить текст, голос и фото между сербским, русским и
английским, с озвучкой перевода.

## 2. Аудитория и доступ

- Только 2 пользователя: Артур (id 199790247) и Кети (id 5276541529).
- Остальным бот отвечает: "Извините, бот личный."

## 3. Функциональные требования

### 3.1 Текстовый перевод
- Пользователь пишет фразу, бот сам определяет язык (сербский / русский / английский).
- Логика направления:
  - сербский -> русский
  - английский -> русский
  - русский -> сербский
- Рядом с переводом показывается флаг направления (🇷🇸 -> 🇷🇺 и т.д.).
- Русский -> сербский дополнительно даёт кнопку "🇬🇧 Перевести на английский".

### 3.2 Определение языка (автодетект)
Приоритет маркеров (в этом порядке):
1. Сербские слова (кириллица и латиница с диакритикой š, ž, ć, č, đ, nj, lj).
2. Спецбуквы сербской кириллицы (љ, њ, џ, ћ, ђ).
3. Сербские латинские диакритические буквы.
4. Русские спецбуквы (ъ, ы, э, щ, ё, й, ю, я, ц, ш).
5. Русские стоп-слова.
6. Доля кириллицы > 50% -> русский.
7. Английские стоп-слова.
8. По умолчанию -> сербский.

Все решения логируются в таблицу lang_detection_log (для отладки).

### 3.3 Голосовой ввод (STT)
- Пользователь шлёт голосовое, бот отвечает: "🎙️ Распознаю и перевожу на русский..."
- Транскрипция: Whisper large-v3-turbo через Groq (language=hint: sr).
- Определение языка по ответу Whisper (serbian/serbo-croatian -> sr, english -> en).
- Переводится на русский и озвучивается.
- Вывод: "🎙 Распознано: <текст> ... <перевод>".
- Если голос уже на русском - перевод не нужен, бот так и сообщает.

### 3.4 Перевод по фото (OCR)
- Пользователь шлёт фото с текстом.
- Распознавание текста: Gemini Vision (gemini-3-flash-preview), возвращает только текст.
- Далее тот же конвейер: определение языка + перевод + озвучка (если не русский).

### 3.5 Озвучка (TTS)
- Google Translate TTS (server-side), ffmpeg конвертация mp3 -> ogg (opus, 48k, atempo 0.85).
- Используется для фото-перевода (озвучка результата на русском).

### 3.6 История диалога
- SQLite (translator_history.db): таблицы dialog_history и lang_detection_log.
- Бот помнит последние ~12 сообщений на чат для связности перевода (контекст в DeepSeek).
- /clear - удалить историю (сейчас просто сообщает об удалении).

## 4. Команды

- /start - приветствие и справка по возможностям.
- /sr - режим: сербский -> русский.
- /ru - режим: русский -> сербский (+ озвучка).
- /en - режим: английский -> русский.
- /clear - очистить историю диалога.

## 5. Технологический стек

- Язык: Python 3.
- Telegram Bot API: прямые HTTP-запросы (requests), long polling getUpdates.
- Перевод: DeepSeek (deepseek-chat, openai SDK, base_url api.deepseek.com).
- STT: Groq Whisper large-v3-turbo.
- OCR: Google Gemini Vision (gemini-3-flash-preview).
- TTS: Google Translate TTS + ffmpeg.
- Хранение: SQLite (история + логи определения языка).
- Ключи/токены: в /root/.openclaw/workspace-neuro/secrets/ и ~/.openclaw-neuro/.

## 6. Обработка ошибок

- Retry-логика для GET/POST (до 2 попыток, уменьшенный таймаут на повторе).
- Retry на getUpdates (до 3 попыток).
- Ошибки перевод/STT/OCR возвращаются пользователю человеческим текстом с 🙁.
- Логирование через logging (файл bot.log).
