# KISELEVY_CREO — Premium Redesign (ТЗ от 2026-08-04)

## Подход
Все премиальные улучшения добавляются **аддитивным слоем**: отдельный блок `<style>` + отдельный блок `<script>`
в конце `index.html`, ПЕРЕД `</body>`. Это гарантирует, что существующая логика (музыка, RU/EN, чат, формы,
Telegram, юридика, портфолио, Oprus, Cmd+K) не ломается.

## Структура премиум-слоя
- `#premium-style`: CSS переменные движения + reveal-анимации + hero + нав + курсор + услуги + тёмная секция + адаптив
- `#premium-script`: IntersectionObserver reveal, кастомный курсор, магнитные кнопки, параллакс медиаблока,
  конденсация шапки, активный пункт меню, генерация тёмной секции

## Безопасность
- `prefers-reduced-motion` -> все анимации отключаются, контент виден сразу
- `@media (hover:hover) and (pointer:fine)` -> кастомный курсор только на desktop
- Мобильные -> тяжёлые эффекты (параллакс, 3D-наклон, курсор) отключены
- Все пути к изображениям относительные (`assets/`)
