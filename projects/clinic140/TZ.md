# Клиника 140 - личный Telegram-бот для Кети

## Цель
Личный Telegram-бот для Кети. 10 врачей-консультантов с суммарным опытом 140 лет.
Полная память диалогов. Личный доступ (Кети - пользователь, Артур - админ).

## Доступ
- Кети (ID: 5276541529) - основной пользователь
- Артур (ID: 199790247) - админ (может править, чинить, смотреть логи)

## Логика
- Главное меню со списком 10 врачей
- Выбор врача → карточка: специализация, стаж, зона ответственности, частые вопросы
- Диалог с врачом
- История КАЖДОГО кабинета - в отдельном файле
- Восстановление после перезапуска (из файлов)
- Автосохранение резервной копии раз в сутки
- Автосохранение после каждого сообщения

## UX
- Главное меню со списком врачей (кнопки)
- Внутри кабинета - чат с именем врача
- Кнопка "назад" (в главное меню)
- Переключение между врачами без потери контекста
- Кнопка "экстренный вопрос" - ответ за 30 сек
- Переключатель стиля ответа: короткий / подробный / пошаговый план
- Режим "консилиум" - несколько врачей обсуждают сложный случай
- Настраиваемые напоминания (выбор времени + частота)
- Экспорт всей истории в PDF по запросу

## Медиа
- Кети прикрепляет: фото, файлы, короткие видео, голосовые (голос → текст через Groq Whisper)
- Врачи отвечают: текст + при необходимости фото из интернета (схемы)

## Стиль ответов
- БЕЗ звёздочек, длинных тире, цветных смайлов
- ТОЛЬКО векторные/монохромные эмодзи
- Живо, по-человечески, без канцелярита

## Оплата
- Бесплатно, без подписок

## Стек
- Python
- aiogram (Telegram Bot API)
- DeepSeek API (LLM)
- SQLite (история/данные - каждый кабинет в отдельном файле)
- Groq Whisper (распознавание голоса)
- reportlab (PDF экспорт)
- systemd (автозапуск)
