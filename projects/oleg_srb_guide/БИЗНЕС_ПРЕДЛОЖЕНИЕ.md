# Бизнес-предложение для Олега (@srb_guide)

Дата: 2026-08-23

---

## Что предлагаем

AI-помощник для твоего комьюнити (~33 000 русских, которые переезжают или уже живут в Сербии).

Человек пишет вопрос (текстом или голосом), бот мгновенно даёт ответ прямо из твоего гайда + ссылку на нужную статью. Плюс встроенный переводчик сербский/русский/английский - голосом и по фото.

---

## Проблема

У тебя в чате 33к человек, и они по кругу задают одни и те же вопросы: ВНЖ, МУП, боравак, прописка, открытие ИП. Гайд у тебя отличный, но среди 90+ статей человеку тяжело самому найти нужный ответ. Ты и модераторы тратите время на повторы.

## Решение

Бот = мгновенный ответ вместо перелопачивания статей. Это не замена твоей миссии, а её усиление: люди по-прежнему решают вопросы сами, без посредников, только быстрее.

## Что уже готово (не обещания, а факт)

- Переводчик @translater_fobs_bot работает в проде: сербский/русский/английский, текст + голос (Groq Whisper) + фото/OCR (Gemini Vision) + озвучка (Google TTS). Это готовый модуль, берём как есть.
- Стек отработан на нейрозаводе: Python + aiogram 3 + DeepSeek + SQLite + systemd.

## Что построим под ключ

1. Парсер статей srb.guide -> база (заголовок + текст + URL + раздел).
2. Поиск по базе (гибридный, для 90 статей векторная БД не нужна).
3. Ответ через DeepSeek по найденным кускам + ссылка на статью. Если в гайде нет ответа - честно пишет "в гайде этого нет", не выдумывает.
4. Встраивание переводчика (готов).
5. (Этап 2) автоответы в группе: типовой вопрос -> ссылка на статью.

## Что получает Олег

- Меньше рутины и повторов в чате.
- Людям - быстрые ответы вместо перелопачивания статей.
- Бесплатно для комьюнити, по твоей миссии - помогать людям.
- Всю технику беру на себя.

## Финансовая модель (кратко)

- Себестоимость запроса копеечная: перевод текстом ~0.015 RSD, голос ~0.01 RSD, фото ~0.01 RSD, вопрос по гайду ~0.11 RSD.
- Бесплатный тариф с лимитами-предохранителями: 15 переводов + 5 вопросов по гайду в день на человека. Потолок ~23 RSD/мес на бесплатника.
- Реалистичная нагрузка (10% активны) ~50 000 RSD/мес на API.
- Платный тариф 1600 RSD/мес: 1 платящий покрывает ~100 бесплатников. Точка безубыточности ~1% конверсии.
- Предохранители от минуса: жёсткие дневные лимиты, кэш повторяющихся фраз, глобальный стоп-кран по расходу, мягкий запуск с тестовой группы.

## Что нужно от Олега

1. Разрешение использовать контент статей srb.guide в боте (парсить можно только с его согласия).
2. (Опционально) разместить бота/ссылку в закрепе чата.
3. (Опционально) добавить бота в группу для автоответов.
