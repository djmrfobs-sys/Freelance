# План: AI-помощник для гайда Олега (@srb_guide)

Дата: 2026-08-22
Автор: Нейро (для Артура)

## 1. Суть и ценность

Бот-помощник в Telegram для комьюнити Олега (~33 000 русских, переезжающих/живущих в Сербии).

Что делает:
- Отвечает на вопросы по переезду и жизни в Сербии, беря ответы из статей srb.guide, со ссылками на нужную статью.
- Встроенный переводчик: сербский/русский/английский голосом и по фото (уже готов).
- (Опционально) автоответы в группе: ловит типовой вопрос и кидает ссылку на статью.

Ключевое: продолжает миссию Олега «помочь людям самим решать вопросы, без посредников».
Бот = мгновенный ответ вместо перелопачивания 90+ статей. Не конфликт с миссией, а её усиление.

## 2. Стек (наши реальные инструменты)

- Python 3 + aiogram 3 (Telegram-фреймворк, уже используется в нейрозаводе).
- DeepSeek (LLM для генерации ответов, ключ уже есть).
- Groq Whisper (распознавание голоса, ключ есть).
- Gemini Vision (OCR фото, ключ есть).
- SQLite (хранение статей: заголовок + текст + URL + раздел).
- Поиск: гибридный (ключевые слова + переранжировка DeepSeek). Для 90 статей векторная БД на старте не обязательна.
- Деплой: systemd (как остальные боты).

## 3. Архитектура (модули)

1. Парсер статей (ingest)
   Обход sitemap srb.guide → скачивание 90+ статей → чистка HTML → чанкинг → SQLite (title, url, section, text).

2. Поиск (retrieval)
   Запрос пользователя → keyword/BM25 по SQLite → топ-5 релевантных кусков.

3. Генерация (generation)
   DeepSeek отвечает по найденным кускам + даёт ссылки на статьи. Если в гайде нет ответа - честно говорит «в гайде этого нет», не выдумывает.

4. Перевод (готовый модуль)
   SR/RU/EN голосом и фото - берём из @translater_fobs_bot как есть.

5. Бот (aiogram)
   Команды /start, /ask (вопрос по гайду), перевод. Inline-режим для группы.

6. Автоответы в группе (опционально, этап 2)
   Бот слушает чат, на типовой вопрос кидает ссылку на статью.

Flow: вопрос → поиск → DeepSeek (с контекстом + ссылки) → ответ.

## 4. Сроки (грубая оценка)

- Парсер + база статей: 1 день
- Поиск + RAG-ответы + ссылки: 1-2 дня
- Интеграция переводчика: 0.5 дня (уже готов)
- Тесты + отладка: 1 день
- Итого MVP: 3-5 дней

## 5. Риски

- Доступ к контенту srb.guide: парсить статьи можно только с разрешения Олега. Спросить обязательно.
- Галлюцинации DeepSeek: обязательная привязка к источникам + правило «нет в гайде - честно сказать».
- Стоимость API: DeepSeek дёшев, но на 33к нужен кэш и rate-limit.
- Юридическое: не давать юридических консультаций, только пересказ гайда с ссылкой.
- Нагрузка: кэш ответов + лимиты, чтобы не лечь при всплеске.

## 8. Финансовая модель (unit-экономика)

### Себестоимость запроса (наши API, RSD)
- Перевод текстом (DeepSeek ~100 токенов): 0.015
- Голос (Groq Whisper, 10 сек): 0.01
- Фото (Gemini OCR): 0.01
- Вопрос по гайду (RAG, DeepSeek с контекстом): 0.11
- Озвучка (Google TTS): 0

### Бесплатный тариф (лимиты-предохранитель)
- 15 переводов (текст/голос/фото) в день
- 5 вопросов по гайду в день

Потолок на одного бесплатника в месяц:
- 15 x 30 x 0.015 = 6.75 RSD (переводы)
- 5 x 30 x 0.11 = 16.5 RSD (гайд)
- Итого ~23 RSD/мес на человека (максимум)

### Сценарии стоимости на 33 000 подписчиков
1. Реалистичный (10% активны, ~10 запросов/день): 3 300 x ~15 = ~50 000 RSD/мес
2. Пессимистичный (20% активны, жмут лимит): 6 600 x 23 = ~153 000 RSD/мес
3. Потолок (все 33к жмут лимит каждый день): 33 000 x 23 = ~767 000 RSD/мес

### Платный тариф (покрытие)
- Подписка 1600 RSD/мес, себестоимость платящего ~50 RSD, чистыми ~1 550 RSD.
- 1 платящий покрывает ~100 бесплатников (1550 / 15).

### Точка безубыточности
- Покрыть 3 300 бесплатников (50 000 RSD) = ~32 платящих = ~1% конверсия.
- 1% = в ноль; 2% = +55 000 RSD/мес; 3% = +108 000 RSD/мес.

### Предохранители от минуса
1. Жёсткие дневные лимиты (15 переводов + 5 RAG).
2. RAG ограничен отдельно (в 7 раз дороже текста).
3. Кэш повторяющихся фраз (перевод + гайд).
4. Глобальный дневной стоп-кран (порог расхода API, после - только премиум).
5. Мягкий запуск (тестовая группа до полного релиза).
