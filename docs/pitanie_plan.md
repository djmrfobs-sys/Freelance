- Двухразовое питание: завтрак + обед, едим до 16:00
- После 16:00 - только вода

### Полностью исключаем
- Сахар, фруктозу, всё со скрытым сахаром
- Мёд (тоже фруктоза)
- Кисломолочные продукты (исключены полностью)
- Глютен (безглютеновая диета)
- Антикандидная диета (AIP-подобный подход)
