# 📚 История переписки с @Fobs_djarvis_bot

Полная архивация всех диалогов Артура с ботом-ассистентом Ментусом.

## Структура папки

- `chat_history_full.json` - полная история в JSON (все сообщения)
- `chat_summary.md` - человеческий формат (краткие итоги)
- `backup_YYYY-MM-DD.json` - резервные копии по дням
- `topics/` - переписка разбита по темам (работа, психология, финансы и т.д.)

## Как это работает

1. **Каждый диалог с ботом сохраняется сразу** в SQLite БД
2. **Каждый час** - экспорт в JSON для резервной копии
3. **При перезагрузке бота** - загружается вся история из JSON
4. **В промпте бота** - последние 15-20 сообщений + контекст о Артуре

## Восстановление после сбоя

Если бот упал:
1. Служба systemd автоматически перезагружает его
2. При старте бот загружает full history из `chat_history_full.json`
3. Восстанавливает все данные: знания об Артуре, его предпочтения, проекты, контакты
4. Продолжает диалог как ни в чём не бывало

## Что сохраняется

- Все сообщения (от Артура и от бота)
- Timestamp каждого сообщения
- Настроение/mood логи Артура
- Расходы и планы
- Контекст: где остановились, о чём говорили, что обещал бот
