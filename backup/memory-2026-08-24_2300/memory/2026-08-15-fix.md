# Патчинг @translater_fobs_bot — Итоговый статус (07:11 UTC)

## Проблема (07:10 UTC)
Артур отправил скриншот: при говорении на сербском бот переводит "всё смешанное", результаты неправильные.

## Причина
**Патч 2 был ошибкой.** Убрав `language="sr"` из Whisper, я надеялся что detect_lang_sr_ru() спасёт ситуацию. Но Whisper на автопилоте путает сербскую речь с русской (они звучат похоже), распознаёт как русский текст, и получается "каша". Потом detect_lang_sr_ru() не может спасить уже испорченный текст.

## Решение (07:11 UTC)
- Вернул `language="sr"` в `transcribe_groq()` 
- Этот параметр **критичен** для надёжного распознания сербского голоса в один проход
- Убрал попытку "двойного прохода" (авто + контрольный) — это замедляет, а не помогает
- Сервис перезапущен (pid 639208)
