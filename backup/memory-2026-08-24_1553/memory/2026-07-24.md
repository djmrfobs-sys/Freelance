## Технические заметки

### Проблема с write()
- Функция `write()` экранирует `process.env.TELEGRAM_BOT_TOKEN` → подставляет многоточие `…` вместо части токена
- **Решение:** Использовать `sed` после `write()` для восстановления: `sed -i 's/proces…/process.env./g'`
- Или использовать `source .env && npx tsx` для выполнения

### LocalTunnel
- Требует заголовка `bypass-tunnel-reminder: true` в сервере для отключения верификационной страницы
- URL меняется при перезапуске — нужна стабильная ссылка (Lovable или выделенный домен)
