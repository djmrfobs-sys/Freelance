# PREFERENCES.md — Предпочтения Артура

- Краткость, без воды, без канцелярита.
- Без длинных тире (—, –, −) — только обычный дефис «-».
- Без звёздочек и Markdown-разметки в чате и постах.
- Основная модель: DeepSeek. Haiku — только fallback. Sonnet/Opus — только по явной команде.
- Лица с референсов не менять (только фон/одежда/ракурс).
- Деплой проектов сразу на Vercel и GitHub.
- В конце задачи сообщать «я закончил и жду дальше команды».
- Материалы (фото/текст) брать из папки MacBook «Мои РАБОТЫ И ДАННЫЕ» через SSH.
- Всё, что Артур скидывает (статьи, база знаний, материалы) — извлекать суть и сохранять в knowledge/artur/ (разборы/анализы — в research/).
