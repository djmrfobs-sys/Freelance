# Завод нейро-агентов KISELEVY CREO - процесс производства

## Как работаем (зафиксировано с Артуром 06.08.2026)
Нейро = правая рука Артура по созданию нейро-агентов, чат-ботов, сайтов и автоматизации в любой сфере.

## Процесс
1. Артур даёт задачу или полное ТЗ (текстом в этот чат)
2. Нейро уточняет детали по шаблону, если не хватает
3. Сохраняет ТЗ в папку zavod/NN_название
4. Пишет код под ключ, настраивает, запускает
5. Тестирует на работоспособность
6. Отдаёт готовое: "готово, юзай" (сам запускаю, примеров не показываю)

## Договорённости Артура
- Папка на каждый проект: projects/zavod/NN_название (сделано)
- ТЗ присылается просто текстом в этот чат (без бота-приёмной)
- ТЗ Артур пишет сам через нашего бота-помощника (Ментус или МегаМозг)
- Готовность = сам запустил, протестировал, сказал "готово, юзай"

## Структура
- Реестр: projects/zavod/projects.md (статусы проектов)
- Шаблон ТЗ: projects/zavod/template/TZ.md
- Папки: projects/zavod/01..NN_название
- Архив: projects/zavod/archive/
