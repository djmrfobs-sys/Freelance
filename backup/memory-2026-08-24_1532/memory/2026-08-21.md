### Шаги на Маке Артура (записать для будущих сессий)
1. Туннель (окно держать открытым): `ssh -N -L 18789:127.0.0.1:18789 root@23.88.127.11`
2. Второе окно: `export OPENCLAW_GATEWAY_TOKEN="9f0696f5ceafb1a048a2206e0df849811e93159f634f3891"`
3. `openclaw node run --host 127.0.0.1 --port 18789 --display-name "MacBook"`
4. На gateway: `openclaw devices list` → approve (или auto-approve по role=node).

### Ключевые команды на gateway (для управления узлом)
- `openclaw nodes status`
- `openclaw nodes describe --node MacBook`
- `openclaw devices list` / `openclaw devices approve <requestId>`
- `openclaw approvals set --node MacBook ...` — настройка exec-approvals на самом Маке (security=full, ask=off)
- Exec на Маке: `exec host=node` (system.run доступен только через exec tool с host=node)

### Нюанс exec-approvals
- Node host кэширует политику approvals в памяти. После `approvals set` нужно перезапустить node run на Маке (Ctrl+C и заново), иначе падает SYSTEM_RUN_DENIED: approval required.
- Файл approvals на Маке: `~/.openclaw/exec-approvals.json`.

### Урок
- При token_mismatch на подключении node — сначала проверить, не два ли gateway на сервере и не в тот ли порт идёт туннель. Порты: 18789=нейро (я), 18790=helper-бот.
