# СТРУКТУРА НЕЙРОЗАВОДА (память и файлы)

Главное правило: каждый тип данных лежит в своей папке, чтобы не вытаскивать всё подряд из одной кучи.

## Корневые папки
- memory/ - память: daily notes (YYYY-MM-DD.md), MEMORY.md (долгосрочная), STRUCTURE.md (этот файл)
- products/ - ГОТОВЫЕ и В РАБОТЕ цифровые продукты (боты, сайты, нейропомощники, воронки)
  - robots/ - Telegram-боты (инвестор, переводчик, ассистент, bagovskaya и др.)
  - sites/ - сайты, лендинги, опросники
  - neuro_assistants/ - нейропомощники (нейропродавец, нейрокоуч и т.д.)
  - funnels/ - воронки продаж
- clients/ - работа по клиентам
- content/ - контент для публикации
  - channels/ - посты в Telegram-каналы
  - reels/ - сценарии Reels
  - campaigns/ - рекламные кампании
- docs/ - документация
  - TZ/ - технические задания
  - contracts/ - договоры и шаблоны
- research/ - исследования, парсинг, анализ, аудиты
- playbooks/ - чек-листы и повторяемые схемы работы (конвейер создания продукта)
- referrals/ - рефералы и партнёрства
- assets/ - медиа: images, audio, documents

## memory/ (память)
- MEMORY.md - долгосрочная память (личное, решения, что запомнить навсегда)
- YYYY-MM-DD.md - дневник по дням
- STRUCTURE.md - описание структуры (этот файл)
- inbox.md - новые задачи/инструкции, которые надо разобрать

## Куда что класть (быстрый справочник)
- Новый бот -> products/robots/<имя>/
- Новый сайт/лендинг -> products/sites/<имя>/
- Нейропомощник -> products/neuro_assistants/<имя>/
- Задача клиента -> clients/<имя клиента>/
- Пост в канал -> content/channels/
- Сценарий Reels -> content/reels/
- ТЗ -> docs/TZ/
- Договор -> docs/contracts/
- Анализ/парсинг -> research/
- Чек-лист/процесс -> playbooks/
- Картинка/аудио -> assets/<тип>/
